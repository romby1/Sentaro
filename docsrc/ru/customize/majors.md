# Слой мажоров

Слой мажоров рисует три вида значимой рыночной активности прямо на графике —
каждый по той цене, по которой он произошёл:

| Слой | Что отмечает |
| --- | --- |
| **Major trades** | Отдельные сделки из верхних 10% по размеру для этого тикера |
| **Clusters** | Одноминутные ценовые уровни, которые поглотили намного больше объёма, чем обычный уровень на этой монете |
| **Liquidations** | Принудительные закрытия позиций от $5 000 |

<Screenshot src="majors" alt="График со слоем мажоров: треугольники сделок и ячейка кластера" caption="Мажоры на 1м графике — треугольники сделок, ячейки кластеров и подсказка одной крупной покупки" />

Это вспомогательный инструмент для чтения графика, а не сканер: он показывает,
**где** прошёл крупный объём на графике, который вы и так смотрите.

## Как включить

Слой включается **для каждого графика отдельно**, не глобально. У каждого
графика есть **кнопка мажоров** на панели инструментов, а стрелочка рядом
открывает меню слоёв.

Также можно нажать клавишу слоя — по умолчанию **<kbd>M</kbd>** — держа курсор
над графиком. Клавиша меняется во вкладке **Home** как **Majors overlay key**,
рядом с клавишами инструментов рисования.

| Инструмент | Где доступен слой |
| --- | --- |
| [Analyzer](/ru/tools/analyzer) | Каждая панель графика и полный экран |
| [Knives](/ru/tools/knives) | Только полный экран |
| [Monitor](/ru/tools/monitor) | Только полный экран |

В Knives и Monitor он намеренно ограничен полным экраном — карточка тикера
слишком мала, чтобы маркеры по ценам можно было прочитать.

::: info Если снять все три слоя, оверлей выключается
Когда вы выключаете все три слоя, выключается и сам оверлей, вместо того чтобы
оставаться включённым и ничего не рисовать. Так что кнопки всегда соответствуют
тому, что вы реально видите. Повторное включение возвращает все три слоя.
:::

## Как читать маркеры

### Крупные сделки — треугольники

Треугольник указывает **в ту сторону, куда толкал агрессор**: вверх и зелёным
для покупки, вниз и красным для продажи. Размер зависит от долларовой величины
сделки относительно самой крупной на экране, так что самый крупный принт в поле
зрения всегда имеет самый большой треугольник.

При наведении видно сторону, размер в долларах, цену, перцентиль, биржу и время.

::: info Что означает перцентиль
Каждая сделка несёт перцентиль, который у неё был **в момент исполнения**.
Пороги пересчитываются для каждого тикера по скользящему 4-часовому окну, так
что `p99` означает, что сделка была в верхнем 1% *именно тогда*, а не
относительно сегодняшнего дня.
:::

### Кластеры — залитые ячейки

Кластер — это одноминутный ценовой уровень, который удержал намного больше
объёма, чем обычный уровень на этой монете. Рисуется залитой ячейкой по этой
цене, с объёмом внутри.

- **Цвет** — доминирующая сторона: зелёный, если покупки перевесили продажи,
  иначе красный.
- **Число** — объём именно доминирующей стороны, а не дельта.
- **Прозрачность** — относительно самого «громкого» уровня *среди видимых
  сейчас*, так что шкала перенормируется при зуме, а не сплющивается из-за
  одного гиганта за экраном.

При наведении видно общий объём, покупки, продажи, дельту и разбивку по споту,
если спотовый объём есть.

::: warning «no clusters — price too stable» — это не ошибка
Уровни шириной около 0.05% — примерно $55 на BTC. Спокойная минута BTC не
проходит такого расстояния, так что вся минута умещается в один уровень, и ни
один не может выделиться на фоне соседей.

На очень стабильных и дорогих монетах кластеров может не быть **вообще**.
Оверлей пишет об этом в строке состояния, вместо того чтобы выглядеть сломанным
на самом популярном тикере из всех.
:::

### Ликвидации — ромбы

Ромб отмечает принудительное закрытие позиции, размер зависит от суммы.

**Цвет соответствует давлению, а не слову.** Ликвидированный *лонг* — это
принудительная *продажа*, поэтому рисуется красным и вниз; ликвидированный
*шорт* — это принудительная покупка, рисуется зелёным. Это легче всего
перепутать, и именно так это работает в ленте ликвидаций в окне Alerts.

При наведении написано словами — `long closed → forced sell` — а также размер,
цена, биржа и время.

## Строка состояния

Оверлей пишет одну строку над графиком. Она намеренно честно сообщает о каждом
ограничении, вместо того чтобы молча показывать неполную картину:

```
MAJORS · all venues · top 25 of 29k trades
```

| Фрагмент | Значение |
| --- | --- |
| `MAJORS · all venues` | Маркеры со всех площадок, которые охватывает поток, — по умолчанию |
| `MAJORS · binance+bybit` / `MAJORS · 4 of 7 venues` | Вы сузили [площадки](#venues): до двух называются, больше — считаются |
| `clusters all venues` | Показывается, когда включён фильтр площадок, — кластеры по нему не фильтруются |
| `candles <биржа>` | Показывается, когда свечи с биржи, с которой маркеры приходить не могут |
| `candles spot` | Показывается, когда вы смотрите спотовый график |
| `top N of M trades` | **В окне было M, нарисованы только N крупнейших** — см. [Markers drawn](#markers-drawn) |
| `no clusters — price too stable` | Объяснено выше |
| `7d max` | Таймфрейм уходит дальше, чем сервер хранит данные |
| `connecting…` / `auth failed` / `feed error` / `no data for this symbol` | Состояние подключения |

### Откуда берутся маркеры

Поток охватывает семь площадок: **Binance** perp и spot, **Bybit** perp и spot,
а также перпы **OKX**, **Gate.io** и **Hyperliquid**. Маркеры для символа
собираются со всех них, с какой бы биржи ни были свечи. Сузить это можно
настройкой [Venues](#venues).

Если свечи с биржи, которой нет среди площадок маркеров, строка состояния
покажет `candles <биржа>`. Sentaro никогда не скрывает это молча.

История уходит на **7 дней** назад. На таймфрейме шире этого левая часть графика
просто не имеет маркеров, а в строке появляется `7d max`.

## Настройки

<Screenshot src="majors-settings" alt="Настройки слоя мажоров во вкладке Home" caption="Home → Majors overlay" />

Фильтры находятся во вкладке **Home**, в секции **Majors overlay**. Они
действуют на все графики во всех инструментах.

### Markers drawn

Сколько крупнейших рисовать, **отдельно для каждого типа**. Диапазон **от 25 до
1500** с шагом 25, по умолчанию 25.

Это настройка именно для **сделок**. В загруженном окне их тысячи, так что на
график попадают только крупнейшие — и строка состояния сообщает, когда такое
обрезание произошло.

Для кластеров и ликвидаций это редко имеет значение: их обычно намного меньше
лимита, так что на деле решают их пороги размера ниже.

### Cluster strength

Скрывает ценовые уровни, которые держат меньше, чем столько объёмов обычного
уровня на этой монете. Диапазон **от 3× до 25×** с шагом 0.5, по умолчанию
5.5×.

- **3×** — всё, что хранит сервер, самое мягкое возможное значение.
- **6×** — только явно сильные уровни.

Поднять это — самый быстрый способ успокоить шумный график, не потеряв важных
уровней.

### Liquidation size

Скрывает ликвидации меньше этой суммы. Диапазон **от $5 000 до $1 000 000** с
шагом $5 000, по умолчанию $15 000.

$5 000 — собственный порог сервера: меньшего он не хранит вообще, так что
минимальное значение уже означает «вообще всё, что есть».

### Venues

С каких площадок могут приходить крупные сделки и ликвидации. Ряд кнопок, по
одной на площадку, с пометкой `perp` или `spot`. По умолчанию **all**.

Нажмите на кнопку, чтобы выключить или включить площадку. Счётчик показывает,
сколько включено, например `4/7`. **All venues** сбрасывает выбор. Выключение
последней площадки возвращает все, так что оверлей никогда не остаётся
включённым без данных.

::: info Кластеры это игнорируют
Кластер объединяет все площадки монеты в один ценовой уровень, так что в нём не
остаётся ничего, что можно отфильтровать по площадке. Когда фильтр включён,
строка состояния напоминает об этом надписью `clusters all venues`.
:::
