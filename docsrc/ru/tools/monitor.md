# Monitor

Monitor ранжирует весь рынок по метрике волатильности и держит верхушку этого
рейтинга на экране. Если [Knives](/ru/tools/knives) ждёт, пока что-то пересечёт
черту, и тогда сообщает, то Monitor — это непрерывно отсортированная таблица
лидеров.

Все показатели считаются по **5-минутным свечам**.

## Как читать окно

### Заголовок окна

Заголовок — это живая сводка действующих сейчас настроек:

- **5m** — таймфрейм свечей. Неизменный.
- **NATR | Vol | Chg** — активная сортировка. Это кнопки: нажмите, чтобы
  пересортировать, не открывая настройки.
- **Детали сортировки** — что именно делает текущая сортировка. Для NATR
  показывает метод сглаживания и режим агрегации (напр. `SMA · Weighted`); для
  Volume — источник и тип (напр. `Total · 75m`); для % Change — просто
  `% Change`. Если действует фильтр минимального объёма, к этому добавляется
  `min $<сумма>`.
- **Пороги оповещений** — `NATR ≥x% · % ≥y%`. Приглушены, когда звук оповещений
  выключен.
- **Vol Ind** — включает или выключает
  [гистограмму объёма](/ru/customize/chart-colors#гистограмма-объема) на
  графиках карточек.
- **Иконки бирж** — включённые биржи в порядке приоритета.
- **Disconnected** — показывается, если связь с данными оборвалась.

### Карточка тикера

Каждая карточка показывает тикер, биржи, где он торгуется, и три метрики:

| Метрика | Значение |
| --- | --- |
| **NATR** | Волатильность — нормализованный средний истинный диапазон, на 5м свечах |
| **Volume** | Объём торгов в долларах за окно, заданное в [Volume type](#volume-type) |
| **% Change** | Изменение цены за 5 минут |

Наведение на логотип биржи показывает `Listed on <биржа>`. У карточек есть
кнопка разворота, которая открывает полноэкранный график с теми же
инструментами рисования, что и в
[Analyzer](/ru/tools/analyzer#инструменты-рисования).

### Что означают цвета

Окраска управляется правилами [цветов метрик](#metric-colors), которые не
связаны с порогами оповещений:

- **NATR** переходит от цвета уровня 1 к цвету уровня 2, когда волатильность
  проходит каждый уровень.
- **% Change** окрашивается по направлению — одна пара цветов для роста, другая
  для падения — и так же повышается на уровне 2.

Если динамические цвета для метрики выключены, она вместо этого просто
подсвечивается при пересечении своего **порога оповещения**.

## Настройки

Откройте вкладку **Monitor** в главном окне.

### Sorting

#### Sort by

Какая метрика ранжирует список: **NATR**, **Volume** или **% Change**. По
умолчанию NATR.

#### NATR method

Алгоритм сглаживания для расчёта NATR. По умолчанию **SMA**.

- **RMA** — скользящее среднее Уайлдера. Глаже, медленнее реагирует.
- **SMA** — простое скользящее среднее. Чувствительнее к недавним свечам.

#### NATR aggregation

Как получается одно значение NATR для тикера, который торгуется на нескольких
биржах. По умолчанию **Weighted**.

- **Weighted** — средневзвешенное по объёму по биржам.
- **Highest** — максимальный NATR среди всех бирж.
- **Priority** — значение с первой биржи в вашем порядке приоритета, у которой
  есть данные для этого тикера.

#### Volume source

Откуда берётся значение объёма. По умолчанию **Total**.

- **Total** — оборот, суммированный по всем включённым биржам.
- **Priority** — оборот только с первой биржи в порядке приоритета.

#### Volume type

Какое окно охватывает значение объёма. По умолчанию **75m**.

- **75m** — скользящий объём за 75 минут.
- **5m** — объём текущей 5-минутной свечи.

::: warning Эта настройка также выбирает, какой фильтр объёма действует
У Monitor два ползунка минимального объёма, и **работает только тот, что
соответствует текущему Volume type**:

- Volume type **75m** → список фильтрует ползунок **Min volume (75m)**.
- Volume type **5m** → список фильтрует ползунок **Min volume (5m)**.

Второй ползунок сохраняет своё значение, но не действует. Если вы выставили
фильтр и не видите результата — проверьте, соответствует ли Volume type тому
ползунку, который вы двигали. Надпись `min $…` в заголовке всегда показывает
тот, что действует на самом деле.
:::

#### Min volume (75m)

Исключает тикеры с объёмом за 75 минут ниже этого значения. Диапазон **от $0 до
$100M** с шагом $1M, по умолчанию 0 — показывается как `None`, то есть без
фильтрации.

#### Min volume (5m)

Исключает тикеры с объёмом текущей 5-минутной свечи ниже этого значения.
Диапазон **от $0 до $10M** с шагом $100K, по умолчанию 0 (`None`).

### Display

#### Max cards

Сколько карточек тикеров показывать. Диапазон **от 3 до 30**, по умолчанию 12.
Список переранжируется на лету при изменении.

### Metric colors

У двух метрик настраиваемые динамические цвета: **NATR** и **% Change**. У
каждой есть главный переключатель, два порога и цвета для текста, контура и
фона.

#### NATR color

Главный переключатель динамической окраски NATR. По умолчанию включено.
Выключено — NATR вместо этого просто подсвечивается при пересечении порога
оповещения.

| Настройка | Что делает | Диапазон | По умолчанию |
| --- | --- | --- | --- |
| **Level 1 threshold** | NATR выше этого использует цвет 1 | 1–10%, шаг 0.5 | 3% (`#A082E8`) |
| **Level 2 threshold** | NATR выше этого использует цвет 2 | 1.5–10%, шаг 0.5 | фактически 7% (`#FFA040`) |
| **Outline** | Цвет рамки для каждого уровня плюс переключатель | — | выключено |
| **Background** | Цвет заливки для каждого уровня плюс переключатель | — | выключено |

::: warning Уровень 2 прибавляется к уровню 1
Значение рядом с ползунком Level 2 — это **Level 1 + Level 2**, а не
собственное значение ползунка. При Level 1 на 3% и ползунке Level 2 на 4%
надпись показывает **7.0%** — именно там на самом деле начинается цвет 2.

То же самое касается ползунка Level 2 для % Change. Читайте надпись, а не
ползунок.
:::

Outline и Background — отдельные переключатели со своими цветами уровней 1 и 2,
так что можно иметь только цветной текст, цветную рамку, залитую карточку или
любую комбинацию.

::: tip Каждый из этих цветов может быть полупрозрачным
Все четырнадцать цветовых слотов здесь используют ту же палитру, что и остальное
приложение, а в ней есть ползунок непрозрачности. Непрозрачность хранится внутри
hex, так что полупрозрачное значение состоит из 8 символов (`#rrggbbaa`), а не
6 — см. [палитру](/ru/customize/chart-colors#палитра).

Больше всего это важно для заливки фона: при полной непрозрачности залитая
карточка перекрывает строку под собой, а примерно на 15–25% лишь подкрашивает
её.
:::

#### % Change direction

Главный переключатель динамической окраски % Change. По умолчанию включено.

Работает как NATR, но с **двумя цветами на уровень** — один для роста, другой
для падения:

| Настройка | Диапазон | По умолчанию |
| --- | --- | --- |
| **Level 1 threshold** | 1–10%, шаг 0.5 | 2% — рост `#4CAF50`, падение `#E05555` |
| **Level 2 threshold** | 1.5–10%, шаг 0.5 | фактически 5% — рост `#00E676`, падение `#FF5252` |
| **Outline** | — | выключено |
| **Background** | — | выключено |

### Иконки бирж

#### Show icons

Показывает или скрывает логотипы бирж на карточках тикеров. По умолчанию
включено.

### Exchanges

Один список с перетаскиванием отвечает и за приоритет, и за включение, и
разделён линией:

- **Выше разделителя** — включённые, пронумерованные по рангу. Ранг важен для
  вариантов `Priority` в NATR aggregation и Volume source.
- **Ниже разделителя** — выключенные. Их ранг показан как `—`, и они не дают
  никаких данных.

Перетащите биржу через разделитель, чтобы включить или выключить её. По
умолчанию порядок такой: **Binance, Bybit, OKX, Gate.io, Hyperliquid**, причём
**Gate.io выключен** — перетащите его выше разделителя, чтобы включить.

::: info
Порядок приоритета по умолчанию в Monitor отличается от Knives (`Bybit, Binance,
Gate.io, OKX, Hyperliquid`). У этих двух инструментов отдельные списки
приоритета — изменение порядка в одном не влияет на другой.
:::

### Alerts

#### Alert sound

Воспроизводит звук, когда тикер достигает порога NATR или % Change ниже. По
умолчанию включено. Когда выключено, надпись порогов в заголовке приглушена.

#### NATR threshold

Подсвечивает и оповещает, когда NATR превышает этот процент. Диапазон **от 3% до
20%** с шагом 0.5%, по умолчанию 5%.

#### % Change threshold

Подсвечивает и оповещает, когда % изменения превышает это значение. Диапазон
**от 3% до 20%** с шагом 0.5%, по умолчанию 4%.

::: info Пороги и цвета — это две разные системы
Пороги оповещений здесь решают, когда сработает *звук*. Уровни
[цветов метрик](#metric-colors) решают, как значение *нарисовано*. Они
настраиваются независимо и могут иметь разные значения — карточка может быть
окрашена, не вызвав звука, и наоборот.
:::
