# Alerts

Alerts стежить одразу за двома речами й показує їх одним потоком: **відхилення
цін** — коли той самий актив коштує по-різному на різних біржах, і **нові
лістинги** — коли токен щойно почав торгуватися на доступній біржі.

::: warning Сторінку ще не перекладено
Повний текст цієї сторінки наразі доступний лише англійською. Переклад
українською готується.

**[Читати англійською → Alerts](/en/tools/alerts)**
:::
