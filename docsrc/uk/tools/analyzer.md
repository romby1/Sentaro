# Analyzer

Analyzer — це робочий простір для графіків: один тікер, кілька таймфреймів
поруч, на обраній вами біржі. Це єдиний інструмент, де можна малювати на
графіках.

::: warning Сторінку ще не перекладено
Повний текст цієї сторінки наразі доступний лише англійською. Переклад
українською готується.

**[Читати англійською → Analyzer](/en/tools/analyzer)**
:::
