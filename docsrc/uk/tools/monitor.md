# Monitor

Monitor ранжує весь ринок за метрикою волатильності й тримає верхівку цього
рейтингу на екрані. Усі значення рахуються за **5-хвилинними свічками**.

::: warning Сторінку ще не перекладено
Повний текст цієї сторінки наразі доступний лише англійською. Переклад
українською готується.

**[Читати англійською → Monitor](/en/tools/monitor)**
:::
