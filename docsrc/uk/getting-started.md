# Початок роботи

Warden — це десктопний застосунок для моніторингу криптовалют під Windows. Він
читає загальнодоступні ринкові дані з Bybit, Binance, Gate.io, OKX та
Hyperliquid і показує їх через набір інструментів, кожен у власному вікні.

::: warning Сторінку ще не перекладено
Повний текст цієї сторінки наразі доступний лише англійською. Переклад
українською готується.

**[Читати англійською → Getting started](/en/getting-started)**
:::
