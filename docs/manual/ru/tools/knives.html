Knives ​

Knives — сканер движения цен. Он следит за каждым тикером на каждой включённой бирже и показывает карточку в тот момент, когда какой-то из них двигается сильнее заданного вами порога — вверх или вниз.

Все его показатели считаются по текущей 5-минутной свече. Тикер появляется потому, что сдвинулась эта свеча, а не из-за 24-часовой цифры.

Как читать окно ​

Пока ничего не сработало ​

Когда ни один порог ещё не пересечён, окно показывает состояние ожидания вместо карточек:

  • Listening — пульсирующая надпись, а за ней по одной записи на каждую включённую биржу: её иконка, процент срабатывания и порог объёма, если для неё включён фильтр объёма. Это живая сводка того, что Knives сейчас готов поймать.
  • No exchanges armed — все биржи выключены. Сработать не может ничего. Включите хотя бы одну в панели настроек.

Карточка тикера ​

Каждая карточка состоит из строки-заголовка и мини-графика под ней.

В заголовке, слева направо:

  • Иконки бирж — на каких биржах торгуется тикер. При наведении показывает Listed on <биржа>. Их можно полностью скрыть — см. Show icons.
  • Значок NEW — тикер залистили в последние 60 секунд. Значок окрашен в цвет биржи, которая его залистила, а при наведении видно, какой именно. Исчезает, как только тикеру больше минуты.
  • Символ тикера — нажмите, чтобы скопировать его в буфер обмена. На миг появится Copied! для подтверждения.

Справа:

  • Объём — объём текущей 5м свечи в долларах. Показывается только когда включено отображение объёма — см. Show volume.
  • Изменение цены — процентное изменение текущей 5м свечи, со знаком.
  • Кнопка разворота — открывает тикер на весь экран.

Что означают цвета ​

Карточка окрашивает свой процент и полоску заголовка в зелёный или красный, как только движение текущей свечи достигает порога % Change этой биржи. Ниже порога показатель остаётся нейтральным.

То есть цвет означает не «цена выросла», а «это движение достигло уровня, о котором вы просили сообщить». Карточка может быть на экране и показывать нейтральный результат, если цена уже откатилась ниже порога.

Направление определяется отдельно для каждой биржи

Для окраски берётся порог той биржи, с которой пришла карточка. Если вы задали разные значения % Change для разных бирж, две карточки с одинаковым процентом могут быть окрашены по-разному.

Полный экран ​

Кнопка разворота открывает один тикер на всё окно с более крупным графиком и переключателем таймфреймов: 1m, 5m, 15m, 30m, 1h, 4h, 1d и 1w.

В выпадающем списке таймфреймы можно отмечать звёздочкой, чтобы закрепить их строкой быстрого доступа рядом с переключателем. Избранные таймфреймы общие с полноэкранными графиками других инструментов.

Гистограмма объёма ​

Кнопка Vol Ind в заголовке окна включает или выключает гистограмму объёма на мини-графиках всех карточек.

Настройки ​

Откройте вкладку Knives в главном окне.

Display ​

Max tickers ​

Сколько карточек тикеров окно показывает одновременно. Диапазон от 3 до 66, по умолчанию 12.

Show volume in tickers ​

Показывает значение объёма в заголовке каждой карточки.

Этот переключатель принудительно включён и заблокирован, когда фильтр объёма включён хотя бы для одной биржи: если вы фильтруете по объёму, Knives всегда показывает объём, по которому фильтровал. Описание при этом меняется на Always on when volume filter is enabled. Чтобы вернуть управление переключателем, выключите фильтр объёма на всех биржах.

Chart data priority ​

Exchange priority ​

Список всех пяти бирж с перетаскиванием. Тяните запись мышью вверх или вниз, чтобы изменить её ранг.

Это определяет, какая биржа поставляет свечи для мини-графика, когда тикер торгуется больше чем на одной. Побеждает первая в списке биржа, которая включена и имеет этот тикер.

На то, какие биржи могут вызвать оповещение, это не влияет — за это отвечает переключатель Enable для каждой биржи ниже.

Иконки бирж ​

Show icons ​

Показывает или скрывает иконки бирж на всех карточках тикеров. Выключено — карточка плотнее и проще; включено — сразу видно, где торгуется тикер.

Настройки для каждой биржи ​

У Knives одинаковый блок настроек для каждой из бирж: Bybit, Binance, Gate.io, OKX и Hyperliquid. Каждая настраивается независимо — пороги, фильтры объёма и включение отдельные для каждой.

Enable <биржа> ​

Получает ли Knives оповещения с этой биржи вообще. Выключено — биржа не сканируется, и её тикеры не могут создавать карточки. Все пять по умолчанию включены.

Выключение биржи делает остальной блок неактивным.

% Change ​

Движение на текущей 5м свече, которое вызывает оповещение для этой биржи. Диапазон от 2% до 10% с шагом 0.5%, по умолчанию 2%.

Это основной порог. Он же определяет, когда показатель карточки становится зелёным или красным.

High threshold ​

Уровень, который считается значительным движением для этой биржи, и точка, на которой срабатывает звук изменения цены. Диапазон от 2% до 10% с шагом 0.5%, по умолчанию 6%.

Этот ползунок прибавляется к % Change

Значение рядом с ползунком — это % Change + High threshold, а не собственное значение ползунка: при % Change 2% и ползунке на 6% надпись показывает 8.0%, и именно там срабатывает звук.

Читайте надпись, а не положение ползунка.

Поскольку значения складываются, повышение % Change поднимает и уровень значительного движения. Сначала задайте базовый порог, а затем настраивайте этот поверх него.

Enable volume filter ​

Фильтрует тикеры этой биржи по объёму торгов, чтобы движения с низкой ликвидностью до вас не доходили. По умолчанию выключено.

Включение для любой биржи также принудительно включает Show volume in tickers.

Volume threshold ​

Минимальный объём в долларах на текущей 5м свече, нужный тикеру, чтобы создать карточку. Диапазон от $100K до $10M с шагом $100K, по умолчанию $1M.

Неактивен, пока для этой биржи не включён фильтр объёма.

Notifications ​

New ticker sound ​

Воспроизводит звук, когда в окне появляется новый тикер.

Price change sound ​

Воспроизводит звук, когда движение достигает уровня значительного движения для этой биржи — числа, показанного рядом с ползунком High threshold.

Срабатывает не больше одного раза на тикер за свечу, так что тикер, который продолжает двигаться в пределах той же 5м свечи, не будет звенеть многократно.

INFO

Оба звука глобальные для Knives, а не отдельные для каждой биржи, независимы друг от друга, и каждый ограничен одним воспроизведением за 2 секунды.

Связанное ​

  • Alerts — расхождения цен между биржами вместо движений на одной
  • Monitor — ранжированный обзор всего рынка вместо ленты срабатываний
  • Графики и рисование — цвета свечей, которые используют мини-графики
  • Слой мажоров — доступен на полноэкранном графике
