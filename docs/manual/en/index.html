Knives
sentaro site

KNIVES

Price movement scanner. Flags any ticker whose current 5m candle moves past a threshold you set per exchange.

ALERTS

Cross-exchange price deviation and new-listing scanner. Shows how far apart the same asset is priced right now.

ANALYZER

Multi-chart workspace. Up to eight panels, any timeframe, five drawing tools, NATR sorting and multiple watchlists.

MONITOR

Live market scanner ranked by volatility. Sort by NATR, volume or % change, aggregated across exchanges.

TICKS

Tape of big trades across nine venues, one card per symbol. Optional TWAP chain detection finds the same order size repeating.

TERMINAL

Experimental trading terminal for Hyperliquid, Binance and Bybit. A proof of concept that places real orders — read the warning first.

CHARTS & DRAWING

Candle colors, drawing color, tool shortcuts and magnet snapping. Applies to charts in every tool.

Sentaro is a monitoring tool. Nothing here is financial advice.
